# Project Lumos - Task 7: Aesthetic Polish & Mobile PWA Touch Ergonomics Pass

## Objective
Elevate the Project Lumos frontend (`src/web`) into a production-grade, tactile, offline-first Progressive Web App (PWA) with bespoke ergonomics for mobile quick-dumping, zero-jank virtual keyboard handling, and tactile micro-interactions on OLED dark canvases.

## Context & Workspace
- Root Workspace: `C:\Users\dannd\Projects\lumos`
- Frontend Codebase: `src/web` (Vite + React 18 + Tailwind CSS + Lucide React)
- Palettes:
  - **Kuro Sakura** (Default): Deep OLED obsidian (`#09090b`), rose/petal accents (`#fb7185`), subtle ambient top wash.
  - **Kuro Midori**: Deep botanikal slate (`#090a09`), emerald/mint accents (`#34d399`).
- Strict Anti-AI-Slop standard: High contrast, crisp 1px borders, subtle ambient glow, zero generic purple-blue gradients or washed-out grays.

## Detailed Requirements

### 1. PWA Manifest & Web App Assets
- Create `src/web/public/manifest.webmanifest`:
  - `name`: "LUMOS · Quick Dump"
  - `short_name`: "Lumos"
  - `start_url`: "/"
  - `display`: "standalone"
  - `background_color`: "#09090b"
  - `theme_color`: "#09090b"
  - `orientation`: "portrait-primary"
  - `icons`:
    - SVG icon `/icon.svg` (purpose: any maskable)
    - Create clean, crisp vector SVG app icons in `src/web/public/icon.svg` featuring a minimalist glowing lantern/spark glyph matching the Lumos design language.
- Update `src/web/index.html`:
  - Add `<link rel="manifest" href="/manifest.webmanifest" />`.
  - Update viewport meta tag:
    `<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover, interactive-widget=resizes-content" />`
  - Ensure Apple mobile status bar and web app capable tags are properly configured.

### 2. Mobile Virtual Keyboard & Safe-Area Ergonomics
- In `src/web/src/components/Composer.tsx`:
  - Handle mobile virtual keyboard transitions without layout jank.
  - Ensure bottom docking respects iOS/Android safe area insets: `env(safe-area-inset-bottom)`.
  - Add auto-focus behavior that doesn't trigger scroll jumps on mobile viewports.
  - Ensure keyboard shortcuts (`Cmd+Enter` / `Ctrl+Enter`) and primary dump button work smoothly.
  - Provide subtle haptic feedback (`navigator.vibrate?.(10)`) on submit and tag clicks.

### 3. Tactile Micro-Interactions & Component Polish
- In `src/web/src/components/MemoCard.tsx`:
  - Add subtle tactile press effect: `active:scale-[0.99] transition-all duration-150`.
  - Ensure pristine text legibility on OLED dark backgrounds (`text-zinc-100`, crisp `#` tag highlights).
  - Add a quick "Copy content" button or action with a checkmark feedback animation.
- In `src/web/src/components/Header.tsx`:
  - Elevate the theme switcher button: smooth tactile feel `active:scale-95`, clean tooltips/labels.
  - Polish the connection badge with an ambient breathing pulse when connected or syncing.
- In `src/web/src/index.css`:
  - Verify and refine CSS variables for both Sakura and Midori themes.
  - Ensure `overscroll-behavior-y: none` and `-webkit-tap-highlight-color: transparent` prevent unwanted browser bounce or gray highlight boxes on mobile taps.

### 4. Verification Gate
- Run `npm run typecheck` across the workspaces.
- Run `npm run build` to verify the production bundle compiles cleanly.
- Keep all existing storage, sync, and API interfaces intact.
